# Doiron Digital: concept sample landing page (Creaition, LLC)
Private preview. Not the live site. `noindex, nofollow`. No analytics, no external requests (fonts are self-hosted).

Preview locally:
    cd /workspace/creaition/doiron-digital/site && python3 -m http.server 8765 --bind 127.0.0.1
    open http://127.0.0.1:8765/

Files: index.html · css/styles.css · js/main.js (no libraries) · fonts/ (Jost, Lora, Playwrite CA; OFL) · assets/ · preview/ (screenshots)
The contact form is front-end only: it never submits or makes a network request.
index.html is generated by ../tools/build_site.py (inlines the camera SVG and icons); editing index.html directly is fine too.
